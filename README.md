🌦 Live Weather Dashboard (Streamlit App)

A real-time weather dashboard built using Streamlit and the Tomorrow.io Weather API.
This app displays current weather conditions and a 5-day weather forecast for Indian cities, including rain, UV index, pressure, wind speed, humidity, and temperature.

🚀 Live Demo

   👉 App Link:
     https://live-weather-forecasting-app.streamlit.app/

✨ Features

  🌡 Current Weather

      Temperature

      Humidity

      Wind Speed

      Rain Intensity

      UV Index

      Surface Pressure

      Weather Code

  📅 5-Day Weather Forecast

     Min & Max Temperature

     Rain Probability

     UV Index

     Pressure

     Wind Speed

  🔄 Auto-refresh every 5 minutes

    📍 City-based weather using geocoding

    ⚡ Fast & lightweight UI
  🛠 Tech Stack

    1.Python

    2.Streamlit

    3.Tomorrow.io Weather API

    4.OpenStreetMap (Nominatim)

    5.Pandas

    6.Requests
